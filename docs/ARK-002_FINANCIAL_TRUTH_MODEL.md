## 1. Purpose

This document defines the Financial Truth Model of Ard Kanaan under ARK-000 and ARK-001. It defines, at a constitutional level, how financial truth exists inside the product. It does not define how anything works.

## 2. Scope

This document defines only constitutional principles about financial truth:

- what creates financial truth
- what never creates financial truth
- which objects are sources of truth
- which objects only present truth
- which objects only provide context
- which objects derive information
- how financial truth remains traceable
- why statements are not sources of truth
- why reports are not sources of truth
- why calculated values are never stored as truth

This document does not define business rules, workflows, implementation, UI, database, fields, validations, numbering, printing, permissions, APIs, storage, architecture, lifecycle, or calculations.

## 3. Financial Truth

Financial truth exists in Ard Kanaan only where the product records financial facts.

The voucher is the sole financial source of truth.

Receipt Vouchers create incoming financial facts.

Payment Vouchers create outgoing financial facts.

Every financial movement has a voucher.

Every voucher represents exactly one financial event.

## 4. Objects That Create Truth

Only Receipt Vouchers and Payment Vouchers create financial truth.

They create financial truth because they are the only objects that create financial facts.

No other object creates financial truth.

## 5. Objects That Never Create Truth

Student Statements never create financial truth.

Financial Reports never create financial truth.

Courses never create financial truth.

The Student does not create financial truth.

These objects may exist inside the product, but they are not sources of financial truth.

## 6. Objects That Present Truth

The Student Statement presents Student financial information.

The Financial Report presents the financial information generated by the product.

Student Statements and Financial Reports present truth, but they are not truth.

Student Statements and Financial Reports depend on voucher-created financial facts.

## 7. Objects That Provide Context

The Course exists only as financial context.

The Course provides financial context inside the Student Statement.

The Course may provide financial context to voucher-created financial facts.

Context is not a source of financial truth.

## 8. Derived Financial Information

The system stores facts.

The system derives results.

Calculated values are never entered manually.

The system never stores derived balances as truth.

Student Statements present derived financial information.

Financial Reports present derived financial information.

Derived financial information depends on voucher-created financial facts.

## 9. Traceability

Every financial value displayed by the system must always be traceable back to its originating voucher.

Traceability preserves the relationship between presented financial information and voucher-created financial facts.

A financial value that cannot be traced back to its originating voucher does not satisfy the Financial Truth Model of Ard Kanaan.

## 10. Truth And Correction

Corrections happen by correcting vouchers.

Corrections never happen by editing statements.

Because vouchers are the source of financial truth, correction belongs to vouchers rather than to objects that only present truth.

## 11. Conceptual Summary

The Student is the central business entity.

The Voucher is the sole financial source of truth.

Receipt Vouchers and Payment Vouchers create financial facts.

Student Statements and Financial Reports present financial information derived from voucher-created financial facts.

Courses provide financial context only.

Financial truth belongs only to voucher-created financial facts.
