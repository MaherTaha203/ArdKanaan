## 1. Purpose

This document defines the complete specification of the Student Statement under ARK-000, ARK-001, ARK-002, and SPEC-001. It defines everything required for the Student Statement as a product object. It does not define implementation, UI, database, or APIs.

## 2. Scope

This document defines only the Student Statement as a product object, including its business purpose, identity, presented information, non-belonging information, and its relationship with the Student, Receipt Voucher, Payment Voucher, Course, Financial Report, and Financial Truth.

This document does not define UI, screen layout, report design, database, implementation, APIs, calculations, numbering, validation, SQL, or printing layout.

## 3. Business Purpose

The Student Statement exists to present the Student's financial information.

It exists because the product must present Student financial truth without turning the Statement into a source of truth.

The Student Statement is a presentation of financial truth.

It never creates financial facts.

It never modifies financial facts.

## 4. Statement Identity

Every Student has one Student Statement.

The Student Statement is the Student's chronological financial history inside the product.

The Student Statement does not become a second Student.

The Student Statement does not become a second source of financial truth.

## 5. Information Presented By The Statement

The Student Statement presents the Student's chronological financial history.

The Student Statement presents financial information derived from voucher truth.

The Student Statement presents course obligations that belong to the Student.

The Student Statement presents financial information contributed by Receipt Vouchers.

The Student Statement presents financial information contributed by Payment Vouchers where applicable.

## 6. Information That Never Belongs To The Statement

The Student Statement never contains independent financial truth.

The Student Statement never contains manually authored financial facts.

The Student Statement never contains manual edits as a source of truth.

The Student Statement never contains academic course management.

The Student Statement never contains information that is not traceable back to voucher truth.

## 7. Relationship With Student

The Student is the central business entity of the product.

The Student Statement belongs to the Student.

The Student Statement exists as the financial history of one Student.

Multiple Students do not share one Student Statement.

## 8. Relationship With Receipt Voucher

Receipt Vouchers contribute financial facts.

Receipt Vouchers contribute financial information to the Student Statement.

The Student Statement presents Receipt Voucher truth without becoming Receipt Voucher truth.

## 9. Relationship With Payment Voucher

Payment Vouchers contribute financial facts where applicable.

Payment Vouchers contribute financial information to the Student Statement where applicable.

The Student Statement presents Payment Voucher truth where applicable without becoming Payment Voucher truth.

## 10. Relationship With Course

Courses exist only as financial context.

Course obligations belong to the same Student Statement.

Multiple Courses never create multiple Student Statements.

The Student Statement presents Course financial context without becoming academic course management.

## 11. Relationship With Financial Report

The Student Statement and the Financial Report are distinct presentation objects.

The Student Statement presents Student financial information.

The Financial Report presents the financial information generated by the product.

The Student Statement does not become a Financial Report.

## 12. Relationship With Financial Truth

The Student Statement is not a source of financial truth.

The Student Statement presents financial truth derived from vouchers.

The Student Statement depends on voucher-created financial facts.

The Student Statement does not create, replace, or override voucher truth.

## 13. Chronological Ordering

The Student Statement is chronological.

Chronological ordering belongs to the identity of the Student Statement as financial history.

## 14. Derived Values

Every financial value shown by the Student Statement is derived.

The Student Statement presents derived financial information.

The Student Statement does not store derived balances as truth.

## 15. Traceability

Every displayed financial value is traceable back to voucher truth.

The Student Statement presents only financial information that remains traceable to its originating voucher.

## 16. Editing Rules

The Student Statement is generated automatically.

The Student Statement is never edited manually.

Corrections occur by correcting vouchers, never by editing the Student Statement.

## 17. Printing

Printing is supported for the Student Statement.

This document does not define print layout or print format.
