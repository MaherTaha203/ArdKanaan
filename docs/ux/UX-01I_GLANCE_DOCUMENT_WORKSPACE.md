# UX-01I — Glance Document Workspace

## Scope

Simplify the Glance into a calm document-like work entry point while preserving the current Owner-approved visual design.

## Changes

- Remove the two-column card/grid composition from Glance.
- Present the cash position as a bordered document section rather than a shadowed card.
- Present student attention as a simple chronological-style list section with light separators.
- Preserve existing actions, derived financial values, navigation, and responsive behavior.
- Keep status and financial meaning textual; no color-only indicators.

## Guardrails

- Home remains an entry point, not a dashboard.
- No charts, KPI wall, analytics workspace, or card grid.
- No financial logic or derived-value changes.
- No domain, schema, store, migration, or Supabase changes.
- No decorative animation, hover effects, gradients, or heavy shadows.
- Existing colors, typography, pill actions, and light RTL visual language remain the active baseline.
